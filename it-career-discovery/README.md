# IT Career Discovery — профориентационная диагностика в IT

Сайт для GitHub Pages + Supabase. Рассчитан на ученицу 11 класса с базовыми навыками работы с компьютером, которая рассматривает поступление в вуз и пока выбирает IT-направление. Это стартовая диагностика, а не школьный экзамен и не тест на «врождённый талант».

## Состав теста
Всего 30 вопросов, ориентировочно 30–35 минут:
- 4 вопроса — цифровая грамотность;
- 7 вопросов — логика и алгоритмическое мышление;
- 4 вопроса — первые шаги в программировании (короткие фрагменты Python);
- 5 вопросов — знакомство с IT-задачами (ИИ, данные, базы, безопасность);
- 10 вопросов — профессиональные интересы.

В интерфейсе они собраны в три крупные части: базовое знакомство с IT (13 объективных вопросов), логика (7) и профессиональные интересы (10).

## Направления профиля
Веб-разработка, машинное обучение и ИИ, аналитика данных, базы данных, сети и инфраструктура, кибербезопасность. Анкета интересов формирует предварительные гипотезы; окончательный выбор проверяется практическими мини-проектами.

## Развёртывание
1. В Supabase открой SQL Editor → New query.
2. Вставь содержимое `schema.sql` из архива и выполни Run. Скрипт рассчитан на повторный запуск и обновляет вопросы с ID 1–30.
3. Проверь, что в конце SQL указан email учителя `valdrmarr@gmail.com`; замени его, если учитель использует другую почту.
4. В Supabase → Authentication → Users создай учётные записи учителя и ученицы, включив Auto Confirm User.
5. Опубликуй содержимое папки `it-test-site` в репозитории GitHub и включи GitHub Pages для ветки `main`.

`config.js` содержит Supabase URL и публичный publishable key. Это клиентские значения, предназначенные для браузера. Никогда не помещай в него `service_role` или secret key.

## Безопасность и результаты
Правильные ответы и пояснения хранятся в `question_keys` и доступны только учителю через RLS. Ученик получает результат без `review` и не может читать таблицу `attempts` напрямую. Результаты и анкета интересов сохраняются в Supabase. Ученик проходит одну попытку; учитель может удалить попытку в кабинете, чтобы разрешить пересдачу.

Отдельный файл `IT-Career-Discovery-key.txt` — офлайн-ключ с правильными ответами и пояснениями для учителя. Не загружай его в публичный репозиторий.
